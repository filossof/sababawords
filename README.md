# SababaWords 🌱

A Duolingo-style web app for Hebrew-speaking kids (10–14) learning English and Arabic,
with a **test-prep mode**: give it a language and a vocabulary list and it generates
levels to get ready for the test.

Design: see [DESIGN.md](DESIGN.md).

## Develop
```
npm install
npm run dev
```

## Deploy (GitHub Pages, `gh-pages` branch)
```
npm run deploy
```
